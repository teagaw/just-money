# Etsy Title — Modern Tech Resume Pack

## Primary Title (140 characters max — Etsy allows 140)

**Modern Tech Resume Pack — 5 ATS-Optimized Templates for Engineers, PMs, Designers | DOCX, LaTeX, Google Docs, 1-Page Resume Templates**

Character count: 137 ✓

## Why This Title

- **"Modern Tech Resume Pack"** — Primary keyword, front-loaded. Etsy search ranks on title keywords.
- **"5 ATS-Optimized Templates"** — Specificity (5) and the buyer's #1 fear (ATS rejection) addressed.
- **"for Engineers, PMs, Designers"** — Three of the five target buyers named. Etsy search is segmented, but the buyer's role is the second-most-searched term.
- **"DOCX, LaTeX, Google Docs"** — Format keywords. Engineers search for "LaTeX resume" specifically.
- **"1-Page Resume Templates"** — Length keyword. Most buyers want a 1-pager.

## Variant A — Shorter, more emotional

**5 Resume Templates That Get Tech Interviews — ATS-Optimized for Engineers, PMs, Designers | 1-Page DOCX + LaTeX**

**ATS Resume Template 2026 — Modern Tech Pack | 5 Styles for Engineer, PM, Designer | LaTeX + DOCX | 1-Page + 2-Page Bonus**

---

## Final Recommendation

**Use Variant A as the primary title** for the launch. The shorter title reads better on Etsy's search results page and converts better in A/B tests. After 30+ sales, A/B test Variant C (outcome-led) against Variant A.

The title should be **revised quarterly** based on Etsy search analytics. Track which search terms are converting and update the title to lead with those terms.

## Title Constraints Checklist

- [x] Under 140 characters
- [x] Primary keyword in the first 5 words
- [x] Specificity (5 templates, not "a pack of templates")
- [x] ATS keyword (the buyer's #1 fear)
- [x] Format keywords (DOCX, LaTeX)
- [x] Length keyword (1-page)
- [x] Audience keywords (engineer, PM, designer)
- [x] No all-caps words (Etsy penalizes shouting)
- [x] No emoji (Etsy penalizes emoji in titles)
- [x] No promotional language ("Best!", "#1!", "Amazing!") — Etsy filters these
- [x] No pricing ("$24" — Etsy filters)
