## How to Build the Actual Canva Files

This repo holds the design **specification** — the source of truth for what the templates look like, how they're laid out, and what content they contain. To produce the deliverable Canva file the buyer downloads:

1. Open Canva → New Design → Instagram Post (1080×1080)
2. Open `design-system.md` and set up the color palette + fonts as a Canva Brand Kit (Canva Pro)
3. Open `post-categories.md` and build each of the 50 layouts page by page, following the layout grids
4. Group the 50 pages into one design titled **"Instagram Small Biz Bundle — 50 Templates"**
5. Use Canva's **Share → Template Link** feature to generate the public template URL
6. The buyer clicks that link, gets their own editable copy, and customizes
7. Build the 10 story templates in a second Canva design (1080×1920)
8. Export the brand guidelines 1-pager + setup guide as PDFs and bundle in the Etsy zip
