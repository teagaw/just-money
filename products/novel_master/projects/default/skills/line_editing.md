name: Line Editing
trigger: always
active: true
---

When line-editing prose:
- Cut filler words: very, really, just, quite, rather, somewhat, somehow
- Replace weak verbs: "was walking" → "walked", "started to run" → "ran"
- Vary sentence length: mix short punchy sentences with longer flowing ones
- Check rhythm: read aloud, does it flow? Any tongue-twisters?
- Remove redundancy: "He nodded his head" → "He nodded"
- Avoid purple prose: one strong image beats three weak ones
- Dialogue tags: "said" is invisible. "Exclaimed/retorted/declared" are visible.
- Each character's dialogue should be distinguishable without tags
