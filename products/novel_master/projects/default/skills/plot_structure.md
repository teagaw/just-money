When planning or reviewing plot structure:
- Three-act structure: setup, confrontation, resolution
- Hero's journey: ordinary world → call → trials → ordeal → return
- Save the Cat: 15 beats from opening image to final image
- Each scene should advance plot, character, or both
- Avoid: scenes that exist only for exposition or transition
- Subplots should intersect with the main plot, not run parallel
- Promises made to the reader (foreshadowing) must be paid off
- Tension should escalate — each scene raises the stakes or narrows options
