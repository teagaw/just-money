When checking for gaps in the story:
- Missing scenes: are there jumps in time/location with no transition?
- Unresolved setups: are there planted elements (objects, questions, promises) with no payoff?
- Continuity gaps: did a character know something they shouldn't?
- Missing character reactions: did a character not react to a major event?
- Unanswered questions: are there reader questions raised but never addressed?
- Missing transitions: does the story flow logically from scene to scene?
- Dropped threads: are there subplots that started but never resolved?
