# Mockup Image Prompts — 5 Marketplace Visuals

> Use these prompts to generate 5 mockup images showing the dashboard in use. Etsy and Gumroad listings with 5+ mockup images convert 2-3× higher than listings with 1-2 images. Each mockup should highlight a different feature of the dashboard so buyers understand the breadth of what they're getting.

**Specs:** 2000x2000 px, 1:1 aspect ratio, PNG, sRGB.

---

## Mockup 1 — Home Dashboard Overview (Hero Shot)

**Purpose:** Show the master Home dashboard in all its glory. This is the "money shot" — the one buyers see first.

**Prompt:**
```
A photorealistic screenshot of a Notion workspace titled "Premium
Notion Fitness Dashboard". Dark mode. The Home page shows: a hero
callout with a flame icon and "Current Streak: 12 days", a 4-column
quick-log row with icons for Workout, Meal, Weight, Sleep, a 3-column
"This Week's Snapshot" with embedded database tables, two gallery
sections for "Active Goals" and "Achieved Goals", a habit heatmap
calendar with teal dots, and a strip of 6 progress photos. The
composition should feel dense but organized, like a control center.
Floating subtly above the screenshot, add a thin gold border with
small drop shadow, suggesting the image is hovering. Background:
dark navy gradient with grain, slightly out of focus. Style:
premium SaaS marketing screenshot. 2000x2000.
```

**Why it works:** Shows buyers the "wow, this is what I'm getting" moment. The visual density communicates value.

## Production Workflow

### Step 1: Generate the Screenshot Base (Figma / Actual Notion)

You have two options:

**Option A — Use the live template:**
1. Set up the template in your own Notion workspace
2. Populate with sample data
3. Take high-DPI screenshots
4. Crop, frame, and annotate in Figma

**Option B — Build a custom Figma mockup:**
1. Recreate the Notion UI in Figma using the official Notion UI kit (free on Figma community)
2. Insert your own data
3. Add annotations and visual flourishes

**Option A is faster and more authentic. Use it.**

### Step 2: Frame Each Screenshot

In Figma:
1. Add a 1-2 px gold border (`#D4AF37`) around each screenshot
2. Add a 0-100-200 soft drop shadow (low blur, low opacity)
3. Place on a dark navy background with a subtle gradient
4. Add a small floating "FEATURE X" tag in the top right of each

### Step 3: Add the Title Bar

Each mockup gets a small text header at the top:

- Mockup 1: "HOME DASHBOARD"
- Mockup 2: "WORKOUTS · CALENDAR VIEW"
- Mockup 3: "PROGRESS · 4-WEEK TRANSFORMATION"
- Mockup 4: "NUTRITION · DAILY + WEEKLY"
- Mockup 5: "MOBILE VIEW · IN THE GYM"

Use the same serif/sans pairing as the cover. Letter spacing: wide. Color: off-white. Size: 12-16pt.

### Step 4: Export

- PNG, 2000x2000 px
- 72 DPI
- sRGB color space
- < 2 MB each (Etsy limit per image, but stay under 1 MB for fast page loads)

### Step 5: Order in Listing

Etsy shows the first image as the cover (in search results). Order them:

1. **Mockup 1 (Hero)** — the main "wow" shot
2. **Mockup 3 (Progress)** — the most shareable, emotional image
3. **Mockup 5 (Mobile)** — addresses the "will it work on my phone?" question
4. **Mockup 2 (Workouts Calendar)** — the most-used feature
5. **Mockup 4 (Nutrition)** — completes the picture

This order front-loads emotional impact (1, 2), addresses the top buyer concern (3), then shows the breadth (4, 5).

## Consistency Checklist

All 5 mockups must use:
- [ ] Same color palette (navy + teal + gold)
- [ ] Same border style (1-2px gold)
- [ ] Same drop shadow style
- [ ] Same font pairing (serif headers, sans body)
- [ ] Same title bar format
- [ ] Same sample data (so the dashboards look consistent across images)

Inconsistency signals "AI generated, no design system." Consistency signals "this brand has taste."
