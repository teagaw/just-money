## Design Notes
- Resolution: 2000x2000 px minimum (Etsy requires 2700x2025 for best zoom)
- Safe zone: keep all visual elements within central 1800x1800 (Etsy adds a 100px frame)
- Color palette must match dashboard design: midnight navy, emerald, warm white, gold accents
- Avoid any text that could be misspelled — keep all visible numbers exact ($63,420, +12%, $2,180 of $2,500, 47%)
- File format: PNG with transparent or solid background, no watermarks
- After generation, lightly post-process: add a subtle vignette, increase contrast by 5%, sharpen edges
