# Quality Bar — What "Premium" Means

This is the non-negotiable standard. **No product lists if it doesn't pass this.**

## Universal Standards (All Lines)

- **Cover image:** 2000x2000px minimum, brand-consistent typography, hint at value (not generic stock)
- **Mockups:** At least 3-5 product mockup images showing actual product in use
- **Description:** Clear, benefit-led, addresses pain → solution → proof
- **Files:** Organized, named clearly, opens cleanly, no broken assets
- **Size:** At least 5-10 "pages" or units of value (no $15 product that's 2 pages)

## Per-Line Standards

### Notion Templates
- 8+ interconnected databases/properties
- Pre-populated with example data (so it doesn't look empty on first open)
- Cover image, icon, all view types configured
- "How to use" Loom-style guide or PDF walkthrough
- Toggle for personal/team mode

### Canva Templates
- 25+ unique pages/elements per pack
- Cohesive color palette (5 colors max)
- 2-3 font pairing
- Editable text/colors (vector or Canva-native)
- Includes matching stories/posts in the same pack
- Bonus: matching brand kit page

### AI Prompt Packs
- 100+ prompts minimum (200+ for premium)
- Organized by style, use case, or both
- Each prompt has: the prompt, the recommended model/params, an example output description
- 10-20 before/after examples
- "How to remix" section

### Spreadsheet Templates
- 8+ sheets (or 1 complex dashboard with 10+ sections)
- Formulas working out of the box
- Conditional formatting for visual punch
- Instructions tab + Tutorial tab
- 3-month example data so users see how it works
- Mobile-friendly tab order

### Resume/CV Templates
- 1-page, 2-page, and cover letter versions
- ATS-passing (clean structure, no tables/graphics that break parsers)
- Editable in Word/DOCX + PDF
- Multiple style options per pack (3-5 looks)
- Sample filled-in version
- "How to customize" guide

## Pre-Listing Checklist

- [ ] Cover image looks like a $200 designer made it
- [ ] All files open cleanly (no broken fonts, missing assets, etc.)
- [ ] Title is keyword-rich (researched via trend-researcher subagent)
- [ ] Description is scannable, benefit-led, ends with clear CTA
- [ ] Tags (Etsy: 13) are all keyword-researched
- [ ] Price is in the $7-29 range (or $27-97 for bundles)
- [ ] Critique subagent gave a "ship it" verdict
