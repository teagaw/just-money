# Just Money — Brand Guidelines

## Brand Name

**Just Money**

- "Just Money" = only money (minimalist, no fluff)
- "Just Money" = fair money (ethical, honest finance)
- Use "Just Money" — not "JustMoney", "Just_Money", or "JustMoney.co" in body copy
- Domain: `justmoney.co` (pending registration)
- Social: @justmoney on Instagram, TikTok, X (pending registration)

## Positioning

> Premium financial tools you own once — no subscriptions, no guilt, no BS.

## Brand Pillars

1. **Ownership Over Access** — Buy it, own it forever. No subscriptions, no upsells.
2. **Real Math, Real Results** — Built on actual financial formulas (NPER, EDATE).
3. **No Shame, No Hustle Culture** — No avocado toast lectures. Tools that work.
4. **Premium by Default** — Every product looks and feels like it costs more than it does.

## Typography

### Primary: Inter

- Headlines: Inter 600 (Semi-bold), 24–48px
- Body: Inter 400 (Regular), 14–16px
- Use for: Product names, UI elements, product descriptions

### Secondary: DM Serif Display

- Taglines: DM Serif Display 400, 18–28px
- Use for: Hero text, premium moments, brand statements

### Monospace: JetBrains Mono

- Numbers: JetBrains Mono 400
- Use for: Spreadsheet data, code-like elements

### Rules

- Never more than 2 typefaces in one layout
- Never use decorative/script fonts
- Never use all-caps for body text

## Voice

### Characteristics

1. **Direct** — Say it simply. No jargon, no hedging.
2. **Empathetic** — Acknowledge the struggle without dwelling on it.
3. **Confident** — We know our product works. We don't oversell.
4. **Witty** — Light humor, never snarky.

### Tone by Context

| Context | Tone | Example |
|---------|------|---------|
| Product Description | Confident + Direct | "This spreadsheet does what YNAB does. For $14.99. Once." |
| Customer Support | Warm + Helpful | "Got it — let's fix that in 2 minutes." |
| Social Media | Witty + Relatable | "Your bank account called. It wants a budget." |
| Error States | Calm + Clear | "Something's off with that formula. Here's the fix." |
| Success Moments | Celebratory + Understated | "Nice. You're $200 closer to your goal." |

### Do / Don't

| ✅ DO | ❌ DON'T |
|-------|----------|
| "You don't need another spreadsheet that makes you feel bad about spending." | "Stop wasting money on frivolous purchases!" |
| "That number is real. It's calculated from YOUR income." | "Our proprietary algorithm determines your optimal budget..." |
| "YNAB charges $109/year. This costs $14.99 once." | "Why pay more when you can pay less?" |
| "Know when you're free." | "Achieve financial independence through disciplined saving!" |
| "Built on real Google Sheets formulas." | "Leveraging institutional-grade financial modeling..." |

### Vocabulary

**Use:** tool, own, real, you, free
**Avoid:** solution, platform, subscribe, advanced, users, leverage, empower, journey, unlock

## Application

### Etsy Listing

- Cover: Clean mockup, white/sage background, logo top-left, price badge in Money Green
- Thumbnail: 3:1 ratio, logo + product name, 3 feature icons max
- Description: Hook → Features → Social proof → What you get → FAQ → CTA

### Gumroad

- Hero: Product name in DM Serif Display, mockup, "Own it forever" callout
- Below fold: Feature grid, comparison table, screenshots, how it works

### Spreadsheet

- Welcome screen: Logo centered, 3 quick-start steps, support email
- Tab colors: Dashboard (Money Green), Income (Ocean Blue), Expenses (Warm Gray), Goals (Soft Gold), Debt (Alert Red), Settings (Light Sage)
- Headers: Deep Charcoal background, white text
- Input cells: Light Sage background
- Negative numbers: Alert Red
- Positive numbers: Money Green
- Footer: "Built with love by Just Money"
